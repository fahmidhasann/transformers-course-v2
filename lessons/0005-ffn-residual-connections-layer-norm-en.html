    FFN, Residual Connections, and Layer Normalization

    Stability, Flow Control, and Feature Extraction inside the Transformer

    Transformer Block Map — Current Position

    Focus of this lesson Rest (other lessons)

    Current Position: this lesson covers what comes after Attention — the Feed-Forward Network, Residual (skip) Connections and Layer Normalization (Add & Norm), highlighted below. The green dashed lines are the residual paths.

    The Unsung Heroes

    We've talked a lot about Attention, which acts like the "ears and eyes" of the Transformer model, looking around the sentence to see how words connect. But Attention alone isn't enough to construct a complete architecture.

    Once the Self-Attention layer looks around and gathers information, it needs a "brain" (processing component) to process that information, and a "safety system" to prevent mathematical instability during training. That's where three unsung heroes come in: Feed-Forward Networks (FFN), Skip Connections, and Layer Normalization.

    1. The "Thinker" (Feed-Forward Network)

    After the Attention step allows words to talk to each other, each word's data needs to be processed individually. This is done by the Feed-Forward Network (FFN).

    How does it work?

    Think of the FFN as a giant memory bank of facts. While Attention says, "Hey, 'barking' is connected to 'dog'," the FFN takes that and says, "Ah, 'dog' plus 'barking' means we are talking about an animal, maybe I should access my facts about pets."

    • Attention: "Who am I connected to?" (Group work)
    • FFN: "Based on those connections, what facts do I know?" (Individual work)
    📐 Mathematical Explanation: Inside FFN

    The Feed-Forward Network is a two-layer neural network with a non-linear activation function (such as GELU or SwiGLU) in the middle:

    FFN(x) = Activation(x W₁ + b₁) W₂ + b₂

    The first layer expands the input dimension (typically 4x) to capture complex factual knowledge, the activation function filters feature activations, and the second layer projects it back to the standard model dimension.

    2. The "Safety Highway" (Skip Connections)

    Modern models like GPT-4 are incredibly "deep," meaning they stack dozens or hundreds of processing layers on top of each other. But there's a problem: as information passes through so many layers, it can get lost or scrambled, causing the model to forget the original inputs.

    The Solution: Direct Bypass Roads

    To fix this, engineers created Skip Connections (or Residual Connections). It works like an express highway running alongside local roads.

    Before a word goes into a complex processing layer, the architecture preserves an unaltered copy of it. The original word takes the "express highway" and jumps straight to the end of the layer, where it is added back to the newly processed data.

    • This ensures the model never loses the original input information.
    • If a layer makes a mistake or distorts feature representations, the preserved copy remains intact to stabilize learning!
    📐 Mathematical Explanation: Backpropagation & Skip Connections

    Mathematically, the residual addition equation is:

    Output = x + SubLayer(x)

    During backpropagation, calculus gives 1 + derivative(SubLayer). The +1 component acts as an unobstructed gradient highway, enabling gradients to flow cleanly to earlier layers without vanishing.

    3. The "Volume Control" (Layer Normalization)

    As the Token Vectors or signals (the numbers we've been talking about) pass through hundreds of layers, they are repeatedly multiplied. Because of this continuous math, the values inside these vectors can explode into insanely huge numbers, or shrink down to zero. The consequences of this happen in two phases:

    • During Training: If these signals get too crazy, the backpropagation process effectively crashes, and training fails to converge.
    • During Inference: (Generating new tokens) If the layers don't receive signals at the correct scale, the model will output complete gibberish.

    To keep these vector signals healthy and stable, we use Layer Normalization (or LayerNorm). You can think of it as an automatic volume knob.

    • If the signals get too loud, LayerNorm turns the volume down.
    • If the signals get too quiet, LayerNorm turns them up.
    • This keeps everything perfectly balanced, so the model can train smoothly and answer correctly during inference.
    📐 Mathematical Explanation: Pre-LN vs Post-LN

    The normalization formula enforces a mean of 0 and a variance of 1 across token features.

    Older Transformer architectures applied normalization after sub-layer computation (Post-LN: LN(x + SubLayer(x))). Modern architectures like Llama, Gemini, and Claude apply normalization before processing (Pre-LN: x + SubLayer(LN(x))), creating a vastly more stable gradient flow during deep network training.
